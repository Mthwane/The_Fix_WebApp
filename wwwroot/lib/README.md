Third-party front-end libraries (Bootstrap, jQuery, etc.) go here.

If using Visual Studio: right-click the project > Add > Client-Side Library
(libman) and restore bootstrap + jquery into this folder, matching the
paths already referenced in Views/Shared/_Layout.cshtml:
  wwwroot/lib/bootstrap/dist/css/bootstrap.min.css
  wwwroot/lib/bootstrap/dist/js/bootstrap.bundle.min.js
  wwwroot/lib/jquery/dist/jquery.min.js
